Qualitative Emotional Journey: How Participants Felt

Tracking user emotional valence throughout the Think-Aloud session ($N=5$). Participants moved from severe cognitive freezing and helplessness on LeetCode to autonomy and joyful mastery on the redesigned prototype.

Stage 01
Problem Onboarding
✕ LeetCode: Blank-page freeze, disorientation, visual clutter.
✓ Prototype: Reassured by clean layout & Guided Checklist.
Stage 02
Deconstructing Code
✕ LeetCode: "Am I doing this right?" No path confirmation.
✓ Prototype: Step-by-step handrails; worked examples build intuition.
Stage 03
Getting Stuck (>15 min)
✕ LeetCode: Imposter syndrome; urge to rage-quit or peek spoiler.
✓ Prototype: Timed 20-min AI hint arrives; relief & confidence surge.
Stage 04
Peer Doubt & Help
✕ LeetCode: Lonely; async comment thread waiting game.
✓ Prototype: Synchronous Study Room; collaborative comfort.
Stage 05
Daily Streak & Exit
✕ LeetCode: Hidden streak in avatar menu; unsaved code anxiety.
✓ Prototype: Prominent streak widget; proud, eager to return.

✦ Evidence-Based Usability Conclusion

Did the prototype successfully improve the user experience?
Yes, comprehensively and conclusively. The qualitative Think-Aloud protocols demonstrate that the redesign transformed negative emotional states (frustration, imposter syndrome, disorientation) into positive states of autonomy, flow, and confidence. Combined with a +115.9% increase in System Usability Scale (SUS 44.0 $\rightarrow$ 95.0), the empirical data validates that procedural scaffolding (Guided Checklist), non-destructive progressive hints (20/40-minute calibrated AI nudges), and synchronous collaboration (Study Room) are critical design patterns for coding education.
